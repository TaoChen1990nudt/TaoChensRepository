这是一款新概念的数字音频工作站，取消了传统的轨道，代之以图层，图层内部可以将音符挂载到不同的音源上，不同图层间可以以Ghost Note的形式同时显示以方便编辑，设置了与音符绑定的自动化编辑窗以及传统的宏自动化编辑窗，增加了编组以及编组统一调整参数，编组也可以选择进行与之绑定的自动化。
This is a new-concept digital audio workstation that eliminates traditional tracks and replaces them with layers. Within a layer, notes can be assigned to different sound sources; notes from different layers can be displayed simultaneously as Ghost Notes to facilitate editing. It features automation editing windows bound to notes as well as traditional macro automation editing windows, and adds grouping along with unified parameter adjustment for groups; groups can also optionally have automation bound to them.
