这是一款新概念的数字音频工作站，取消了传统的轨道，代之以图层，图层内部可以将音符挂载到不同的音源上，同层间可以以Ghost Note的形式同时显示以方便编辑，设置了与音符绑定的自动化编辑窗以及传统的宏自动化编辑窗，增加了编组以及编组统一调整参数与自动化功能。
This is a new-concept digital audio workstation. It eliminates traditional tracks and replaces them with layers. Within a layer, notes can be assigned to different sound sources; within the same layer, notes can be displayed simultaneously as ghost notes to facilitate editing. It provides automation editing windows bound to notes as well as traditional macro automation editing windows, and adds grouping along with unified parameter adjustment and automation functions for groups.
