## Phase 56：多选拉伸、组粘贴、复制到后一小节

### 需求
1. 多个采样选中时，拖长度要一起改。
2. 组的复制粘贴，粘贴出来必须是组，不是散开的组内容。
3. 组的右键菜单要有「复制到后一小节」。

### 实现
- **多选拉伸**：`applySampleTrimDrag(主块, 目标, 边, 兄弟原件)`。先按 P29 的规则摆主块，
  再把**实际 delta** 读回来给兄弟（尾 `length += delta`，头 `start += delta` 且终点钉住）。
  兄弟各走同一个 `applySampleTrim`，各自的 offset 与最小长度照旧生效。
  `dragTrimOriginals` 在 mouseDown 抓住选中块的边时捕获；`simulateSampleTrim` 走同一条路。
- **组粘贴**：`isWholeGroupSelected(groupId, includeSamples = false)`（挂载不看块、复制要看块）；
  `copyNotesToClipboard` 认整组时把块一并放进 `sampleClip`（不再依赖调用方追加第二次 pass）；
  `pasteEditClipboard` 见 `groupClip.valid` 直接走 `pasteGroupFromClipboard()`：一个锚点、
  一次建组、音符与块都写 `newGroupId`。抽出 `captureGroupClip` / `addGroupCopy` /
  `insertGroupMembers`，`duplicateGroupToNextBar` 复用同一套。
  `cutNotesToClipboard` 补：整组剪切时把块也从时间线删掉（否则剪切→粘贴会复制一份没搬走的音频）。
- **复制到后一小节**：`duplicateGroupToNextBar(layerIndex, groupId)`，模型级克隆，不动剪贴板。
  目标 `nextBarLineAfter(起点)`；若仍压源上则 `barLineAtOrAfter(源结束)`。菜单项 id 8，
  放在「选中整组」下面。菜单构造抽成 `fillGroupMenu(menu, ...)` 供自检读（showMenuAsync 无法在
  headless 里观察）。
- `SharedRules.h` 新增 `beatsPerBar` / `nextBarLineAfter` / `barLineAtOrAfter`，标尺不再写字面量。

## Phase 57：组框贴住成员、粘贴复用源组

### 需求
1. 组的边框与采样的边框之间不要留距离。
2. 组粘贴之后不要重新新建一个组，而是复用被粘贴的组。

### 实现
- **组框零外扩**：`groupFrameOf()` 返回 `getGroupContentBounds()` 本身（去掉 `expanded(3px)`）。
  3px 原本是"组线画在成员之下、不外扩就被块的填充吃掉"的补丁；现在把描边拆到成员**之上**
  单独画（新函数 `drawGroupFrames`，插在 `drawNotes` 之后），填充仍留在 `drawGroupBands`。
  描边向内容框内缩半个线宽，正好压在块自己那圈边框上。
  绘制、命中（`getGroupFrameAt`）、自检都调 `groupFrameOf` —— 画的和测的是同一个函数。
- **粘贴复用组**：`GroupClip` 新增 `sourceGroupId`（`captureGroupClip` 写入）。
  `pasteGroupFromClipboard()` 先看 `active->findGroup(sourceGroupId)`：
  在 → 直接往里加成员（同一 name/colour/mount/trim/曲线）；不在（剪切榨干、跨图层）→
  `addGroupCopy` 建一个同名同色的新组。清理改成 `if (! reused) removeGroup(...)`。
- **统一粘贴入口**：`pasteNotesFromClipboard()` 开头见 `groupClip.valid` 就转发给
  `pasteGroupFromClipboard()`，否则旧入口会以"散音符"身份粘一遍、块留在剪贴板上。
  `duplicateGroupToNextBar()` 仍新建组（那是"再来一份"）。

### 咬测（3 处，全部先 FAIL 后还原）
1. `groupFrameOf` 恢复 `expanded(3px)` → 零间隙断言 FAIL（frame 103.8 / block 96）。
2. `reused = false`（恒新建组）→ 三条粘贴断言 FAIL（1→2 组、组内 3 音符等）。
3. 删掉旧入口的转发 → "组内现 4 音符 / 1 采样"、"粘贴后选区 2 notes / 0 clips" FAIL。

### 结果

formatVersion 仍 23（无模型字段变化）。快照 `docs/phase57.png` 已目视：组框与

## Phase 58 — 组 = 一个定义 + 多次出现

用户五条，全部指向同一处模型的缺口：P57 让"粘贴"把副本**借给源组**，于是副本和源共用一个
括号——"拖动长度有时失败"是另一件事，但"粘到了组的内部""复用对象之间移动不独立"是它的必然。

### 模型
`NoteGroup` 从此只是**定义**；时间线上的每一份是它的一次**出现**。
- `NoteEvent` / `SampleEvent` 各加 `int groupOccurrence = 0`（默认 0 = 老工程 = 第 0 次出现）。
- 新 API：`assignNotes/SamplesToGroup(ids, gid, occurrence = 0)`、`getGroupOccurrences(gid)`
  （派生、升序）、`nextGroupOccurrence(gid)`、`getOccurrenceNoteIds/SampleIds`、
  `countNotes/SamplesInOccurrence`、`getGroupOccurrenceOfNote/Sample`。
- `removeGroup` / 悬空组修复同时把 occurrence 归 0。
- 约定：**`occurrence < 0` = 该组所有出现**，`>= 0` = 只那一次。所有新参数的默认值都取这个，
  所以老调用点行为不变。
- `formatVersion` 23 → 24：`<Note>` / `<Sample>` 增 `groupocc`，只在非 0 时写。

### 五条需求各落在哪
1. **选中采样后拖长度有时失败** → 根因是拾取顺序。`hitTestSample` 改成**倒序**（最上层优先），
   mouseDown 块分支加"已选块的边缘优先"：`selectedTrimEdgeAt(pos)` 命中就以它为准，
   且**不改写选区**；`mouseMove` 同步显示左右箭头光标。拖动时 `grabbedId` 用它。
2. **播放头回到原处时滚动条要复原** → `setScrollBeats` / `setBeatWidthAround` 末尾
   `noteUserScroll()` 记住用户视野；`setPlayheadBeat` 开头先判断播放头是否落回该视野，
   是就滚回去并停止跟随。跟随不再是单向的。
3. **粘贴组粘到了组内部** → `pasteGroupFromClipboard()` 仍复用源 `NoteGroup`，但用
   `nextGroupOccurrence()` 生成新出现号，`insertGroupMembers(..., occurrence, ...)` 写进去。
4. **编组栏的组拖到钢琴窗 = 放一处** → `atomic-group:<层>:<组>` payload；
   `GroupPanel` 的 body 按下只 arm，超 4px `startDragging`，折叠延后到 `mouseUp`；
   落点唯一实现 `PianoRollComponent::placeGroupAppearance()`（模板 = 该组最早一次出现），
   预览画落点竖线 + 虚线跨度幽灵 + 标签「放一处 <组名>」。
5. **各出现独立移动** → 拖动/复制/解散/框/标签/自检全部按次：`getGroupContentBounds`、
   `captureGroupClips`、`armGroupMove`、`simulateGroupMove`、`duplicateGroupToNextBar`、
   `disbandGroup`（该组还有别处时只解这一次，只剩这一处才 `removeGroup`）、
   `drawGroupBands/Frames/Labels`（双层循环，每处一个括号一个标签）、`getGroupBeatSpan`、
   `isWholeGroupSelected`、`selectGroup`、新增 `getSelectedGroupOccurrence`。
   引擎侧：`ScheduledNote/ScheduledClip.groupOccurrence`、`Scope.groupOccurrence`
   （-1 = 所有出现），所以"只渲染这一处"能选。

- 改写 3 条因语义变化失效的：P24 的"新组带曲线" → "多一处出现、共享同一条曲线"；

## Phase 59 — 拉伸拾取收进块内、编组栏镜像、折叠行只留组名

三条都小，但第一条是"看着像功能缺失、其实是量纲/范围写错"的典型。

### 1. 选中多个采样拖动长度，只有最右边那块有效
根因：`selectedTrimEdgeAt` 的 band 判定只有一半。
- `x >= right - band` 没配 `x <= right` → 对块**右边一切像素**成立；
- `x <= left + band` 没配 `x >= left` → 对块**左边一切像素**成立。
选中 A/B/C 三块相邻，按 B 的尾巴：倒序遍历先问 C，`x <= C.left + band` 命中 → 返回"C 的头"。
拖 C 的头 = 移动 `sourceOffsetSeconds`，已贴底 → `jlimit` 夹住 → delta = 0 → 什么都不动。
用户看到"按了没反应"，而且只有最右那块的头没有右邻居、尾没有遮拦，所以"只有它能拖"。
修法两层：①要求指针在块内（x 与 y 都在）；②命中后按**距离最近**的边定 tail/head，
并用倒序遍历 + 严格小于让最上层赢平局（A.right 与 B.left 是同一个像素）。
自检走 `getBlockGrabAtForTest`（拾取的唯一顺序），再加一条端到端：
抓中块尾巴 → `simulateSampleTrim` → 三块按**同一个 delta** 变短（0.946 / 0.946 / 0.946）。

### 2. 组在钢琴窗选中时，编组栏那行要高亮
新增 `PianoRollComponent::getSelectedGroups()`（派生，不存 flag）：每个组的每个出现问一次
`isWholeGroupSelected(gid, true, occ)`，任一出现整体入选即算。主窗体在 `onSelectionChanged`
里用 `syncGroupPanelSelection()` 推给 `GroupPanel::setSelectedGroups(rows)`，面板按
`(layerIndex, groupId)` 比较（组在 vector 里，指针会失效）。
绘制用组色 15% 填充 + 60% 描边；**左竖条留给"喂给聚光灯音源"**那个已有标记，两者可同时出现。

### 3. 折叠之后的组名背后有字

（`x=46, w=width-106, y+4, h=18`）。直接删掉那段：折叠 = 一行，那行是标题。

## Phase 61 — 缩放视口：不够就加长、多了就还回去（同一档）

### 现象
把钢琴窗缩到很宽（Ctrl+滚轮往左、拖标尺）时，视口宽度越过标尺长度的**那一档**不加长，
下一档才加长；中间那一段右边是一条没有网格、没有小节线的死带。缩回去时反倒正常。

### 根因（PITFALLS P61-A）
`clampScroll()` 里：`if (scrollBeats + visibleBeats > timelineBeats) ensureTimelineExtendsTo (...)`。
缩放以某一拍为锚，锚点常在 beat 0 左边，`scrollBeats` 在这里是**负数**，两行之后才被
`jlimit(0, maxBeats, …)` 夹回 0。用负数求和把需求算小了：`-16.6 + 74.5 = 57.9 < 64`，
于是"64 够长"；而真正要显示的是 `[0, 74.5]`。

### 修法
```cpp
const double wanted = juce::jmax (0.0, scrollBeats) + visibleBeats;
if (wanted > timelineBeats) ensureTimelineExtendsTo (wanted);
```
顺序固定为「夹下界 → 问需求 → 夹上界 → 回收」，不新增入口：
缩放的 `setBeatWidthAround()` 本来就调 `clampScroll()`，加长与回收都在那一处结算。
回收不用另写——`visible` 变小后 `trimTimelineToView()` 自然把长度落回 `beatChunk` 的整数倍，
滑块宽度跟着恢复。

### 实测
- 每一档都满足 `visible <= timelineBeats`：`41.4视/64长 → 74.52视/128长 → 92视/128长`（旧：`74.52视/64长`）。
- 缩回去：`128 -> 64 beats`，滑块宽 `394.594 -> 394.594`（完全回到原位）。

### 自检（+2：543 → 545）
1. "Zooming out lengthens the roll on the same notch, not the next one" —— 8 档逐档检查
   `visible <= timelineBeats`，并记录每档数字；只查最后一档会漏掉"差一档"。
2. "Zooming back in gives the extra ruler back, thumb included" —— 长度与滑块宽度同时回到基准。

### 咬测（2 处，全部先 FAIL 后还原）
1. `wanted` 去掉 `jmax(0.0, …)` → `74.52视/64长`，正中死带现象。
2. `clampScroll()` 末尾不调 `trimTimelineToView()` → 缩放后 `128 -> 128`、滑块 `394.594 -> 197.297`。

### 结果
编译零 error 零 warning；**545 PASS / 0 FAIL / EXIT=0**；`formatVersion` 仍是 24，工程文件格式未动。
探针（临时 fopen 调试输出 + 临时 check）已全部清除，`grep -c "DBG \|p61dbg"` 为 0。

2. 复制粘贴编组时**有时候会取消已经编组的组**。

### 模型（P58 只做到一半）
P58 让组 = 定义 + 多次出现，但"定义"里只有 name/颜色/挂载/trim/曲线；**成员内容是各存一份的**，
所以两处出现可以长得不一样——这正是需求 1 的缺口。

P62 把语义补成：**出现只拥有位置，其余都是组的。**
- `NoteGroup::occurrenceStarts`（`map<int,double>`）：每次出现的起始拍。
  **必须存**：只按"最早成员"推导的话，删掉那个成员位置就会跟着走，之后每次同步把这一处拖一次。
  `Layer::occurrenceStart()` 第一次被问到时物化并写回，此后只在**整处移动**时改（`setOccurrenceStart`）。
- `Layer::syncGroupShape(gid, source)`：按成员序 `(start, pitch, id)` 配对，
  把源出现的"相对起点 + 全部属性"写进每个兄弟出现，锚点用兄弟自己的起点。多退少补，
  相同则一个字节都不改（`sameNoteShape` / `sameClipShape`），所以整处拖动时它是零开销的空转。
- `Layer::collectTwinMembers(notes, clips, twinNotes, twinClips)`：**离开形状**没有模板可抄，
  在原件还在时按序号配对，返回兄弟出现里的对应成员。

### 唯一判据：整处 / 局部
- 整处拖动、整处删除 = **对这一份副本的决定**，兄弟不动。
- 动一部分 = **形状变了**，兄弟跟着变。
拖动侧 `wholeGroupOccurrencesInDrag()`（数成员），删除/解组侧 `isWholeGroupSelected(gid,true,occ)`。

### 同步挂在哪
挂在**编辑动作本身**，不只在 mouseUp（否则拖的时候兄弟不动、松手才跳）：
`applyMove`、`applyNoteResize`、`dragAutomationPoint`（音符包络）、采样曲线拖动、
`applySampleTrim`、`splitNotesAt`、`splitSamplesAt`、`toggleSelectedSampleReverse`、
`setSampleStretchMode` / `setSelectedSampleStretchMode`、块的 laneSpan ±。mouseUp 那份是兜底
（内联框那类"没有拖动"的编辑靠它）。
起点钉住的三处：`groupSelection()`（建组）、`insertGroupMembers()`（粘贴/放一处/复制到后一小节）、
`materialiseOccurrenceStarts()`（读工程）。

### 需求 2 的根因（P62-A）
`copyNotesToClipboard()` 用 `isWholeGroupSelected(groupId, true)`，默认 occurrence = -1 = **全组**。
组只有一处时选满它满足；**一旦有两处**，选其中一处永远凑不齐 → 落到散音符分支：
音符保留 `groupId`（粘贴时粘回源出现）、采样块被 `clip.groupId = -1` 扒出组。这就是"有时候"。
修：`getSelectedGroupOccurrence()` 拿到"哪一处"再问整不整；散音符粘贴**显式** `groupId = -1`。

老文件没有这些元素 → 懒物化，打开即正确、不会移动。`docs/demo.atomic` 随自检重存，只有 version 变了。
