## Phase 45 — const 设计债还清（2026-10-27 晨，P44 同日续）

### 战术修正

P44 说"还债要逐函数决定"，实际做的比预想顺：错误映射后真相是 **28 个出错函数里
24 个本来就不是 const**（mouseDown / applyMove / groupSelection / pasteNotes…全在列）。
它们的错误不是"const 函数写模型"，而是机械替换把非 const 函数里的
`auto* layer = stack.getLayer(...)` 也错误地升级成了 `const auto*`——可变链被切断。
修正：非 const 函数体内恢复 `auto*`（65 行），错误从 50 个瞬间掉到 4 个。

真正"const 函数返回可变指针"的只有 5 个：

| 方法 | 处理 |
|---|---|
| `Layer::findNote` | 补 const 版（返回 `const NoteEvent*`），模型层 |
| `hitTestActiveLayer` | 双版本：非 const 返回 `NoteEvent*`，const 返回 `const NoteEvent*` |
| `hitTestSample` | 同上（SampleEvent） |
| `getExpandedNote` / `getExpandedGroup` | 同上 |
| `groupLaneFor` | 双版本（`NoteGroup&` → `NoteGroup&` / `const NoteGroup&` → `const AutomationLane&`） |

调用点**零修改**：C++ 按 this 的 const 自动分派，const 绘制函数拿到 const 指针，
编辑手势拿到可变指针。AutomationLane / NoteGroup::automationFor / findGroup / findSample
的双版本本来就存在——模型层当初是照着对的形状写的，只有 findNote 和这五个 UI 方法漏了。

另修一处机械替换自伤：const 函数里 `const auto*` 被重复前缀成 `const const auto*`（12 行），正则化一次修回。

## Phase 46 — 混音链三件套：EQ / 压缩 / 混响（2026-10-27 午）

来源：项目潜力评估的结论——"吸引制作人的第一刀是补 EQ/压缩/混响"。

### 实现（Effects.h 单点，四类只改一处）

- **枚举追加在 vst 之后**（eq=6 / comp=7 / reverb=8，numTypes 9）。vst=5 被老工程文件冻结，
  重排会把每个存档 VST3 变成 EQ。菜单循环从 `type < numBuiltInTypes()` 改为全枚举 + 显式跳过 vst
  （旧写法在枚举增长后会把 eq/comp/reverb 当成 vst 卖给用户）。
- **EQ = 倾斜均衡**：一个旋钮（p1，0.5=平），800 Hz 支点单极分频，`y = x + k·(high − low)`，
  k = ±0.5。拉高/拉低两端朝相反方向动，音乐上比四段 EQ 的两个参数更直觉。
- **COMP**：p1 一档管两件事（阈值 −6→−26 dB + 比率 2:1→8:1），链接立体声包络
  （max(|L|,|R|)，不晃声像），5 ms 起 / 150 ms 放，固定温和 makeup（1+0.35p）。
- **REVERB**：每声道 4 梳状 + 2 全通（Schroeder），p1 = 房间大小（反馈 0.70→0.96），
  右声道延迟线 +1.3% 失谐展开立体声，湿量固定 30%×0.6。内存 12 条延迟线在 prepare()
  按采样率算长度，音频线程只走位置。
- SlotState 新增 verbBuffer/verbLen/verbPos/verbDamp + compEnv/compGain；prepare/reset 同步。
