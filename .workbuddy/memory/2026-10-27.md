## Phase 45 — const 设计债还清（2026-10-27 晨，P44 同日续）

### 战术修正

## Phase 46 — 混音链三件套：EQ / 压缩 / 混响（2026-10-27 午）

来源：项目潜力评估的结论——"吸引制作人的第一刀是补 EQ/压缩/混响"。

### 实现（Effects.h 单点，四类只改一处）

- **枚举追加在 vst 之后**（eq=6 / comp=7 / reverb=8，numTypes 9）。vst=5 被老工程文件冻结，
  重排会把每个存档 VST3 变成 EQ。菜单循环从 `type < numBuiltInTypes()` 改为全枚举 + 显式跳过 vst
  （旧写法在枚举增长后会把 eq/comp/reverb 当成 vst 卖给用户）。
- **EQ = 倾斜均衡**：一个旋钮（p1，0.5=平），800 Hz 支点单极分频，`y = x + k·(high − low)`，
  k = ±0.5。拉高/拉低两端朝相反方向动，音乐上比四段 EQ 的两个参数更直觉。
- **COMP**：p1 一档管两件事（阈值 −6→−26 dB + 比率 2:1→8:1），链接立体声包络
  （max(|L|,|R|)，不晃声像），5 ms 起 / 150 ms 放，固定温和 makeup（1+0.35p）。
- **REVERB**：每声道 4 梳状 + 2 全通（Schroeder），p1 = 房间大小（反馈 0.70→0.96），
  右声道延迟线 +1.3% 失谐展开立体声，湿量固定 30%×0.6。内存 12 条延迟线在 prepare()
  按采样率算长度，音频线程只走位置。
- SlotState 新增 verbBuffer/verbLen/verbPos/verbDamp + compEnv/compGain；prepare/reset 同步。

## Phase 47 — 效果器多参数化 + 编辑窗口按键（2026-10-27 晚）

### 一、参数模型：p1/p2 → params[9]（Effects.h 单一来源）

`Settings::params` 固定 9 槽归一化 0..1，取代 p1/p2（引用处 15 个全部同步）。
**参数映射表收进 Effects.h 一处**（`numParams / paramName(type,i) / paramText(type,i,v)` +
各 `xxxDb/Secs/Hz` 映射函数）——DSP 用什么数、编辑窗口印什么数，是同一张表，
"P43 id 撞车"的教训推广到参数上。机架 mini 条沿用单参 `paramName(type)`（EQ/THR/LEN）。

- **EQ 九参**：低/中/高频频率（log 映射 20–600 / 200–5k / 1.5k–16k）、三增益（±12 dB，
  0.5=0dB）、三 Q（0.3–8）。DSP = RBJ biquad 三段串（low shelf / peaking / high shelf），
  **0 dB 的频段整个旁通**——没动的频段必须位透明。
- **COMP 六参**：阈值 −40..0 dB、比率 1..20（log）、补偿 0..+18 dB、启动 1..200 ms、
  释放 20..2000 ms、拐点 0..24 dB（Reiss & McPherson 软拐点二次式；knee<0.01 走硬分支防除零）。
- **REVERB 五参**：长度（0.2..10 s，RT60 式反馈 `g=10^(−3·len/(T·sr))`）、空间大小
  （0.2..1.8x，乘每条线有效长度——verbBuffer 按 1.85x 预分配，音频线程只走位置）、
  低切 20..800 Hz、高切 2k..18 kHz（湿路径一阶滤波）、散射度（全通系数 0.25..0.70）。
- `setInsertType` 换类型时按 `defaultParam` 重置全部旋钮——换挂 EQ 不能继承延迟的反馈值。

# Phase 49 — 采样块的音量曲线（淡入淡出退场）

## 需求

采样块向下展开一条自动化栏，**宽度与采样块同款**，同时**去掉淡入淡出**。

## 做法

- **模型**：`SampleEvent` 删 `fadeInBeats` / `fadeOutBeats`，加 `NoteEnvelope volumeCurve`
  （归一化时间 0..1，`makeIdle()` = 平线 1.0 且**禁用**——新块就是"文件原样"，
  第一次编辑才点亮，与音符包络同一套语义）。
- **音频**：`ScheduledClip` 删 fade 字段，加 `gainAutomated` + `gainCurve`（x 已是**秒**）。
  `publishSchedule` 里 `p.time * blockSeconds` 一次换算，渲染循环只做 `automationValueAt` 求值。
  咔哒 ramp 保留：全下压的曲线仍然是静音而不是爆音。
- **工程文件**：v20 → **v21**。writer 不再写 `fadein`/`fadeout`，改写 `<Envelope>`；
  reader 读到老属性就**迁移成等价斜坡**（fadeIn → 0→1，fadeOut → 1→0，两段可拼）。
- **UI**：块尾 chevron（复用音符尾键的几何与画法）+ 向下展开箱（宽 = 块宽，无空间时翻到块上方）；
  曲线点拖/加/删、菜单行"音量"+ 启用开关 + 关闭叉号；与音符箱/编组箱三选一互斥。
  删除全套淡变：`drawSampleFades` / `hitTestSampleFadeHandle` / `applySampleFade` /
  `getSampleFadeHandleX` / `simulateSampleFade` / `fadeSampleIn|Out` 两个 DragMode / `kFade*` 三个常量。

## 两个真问题（咬测咬出来的）

1. **音频断言天生看不见单位错**：夹具的块正好 2 拍 = 1.0 s，于是"归一化 x"和"秒 x"是同一个数，
   把 `p.time * blockSeconds` 改成 `p.time` 断言全过。改成 **8 拍（4 s）** 的块 +
   "同一窗口开/关曲线的比值 vs 曲线应有值"（1.0 s 应 0.250、1.6 s 应 0.400），才咬得住（实测 0.237/0.388）。
2. **`cmd //c "... & echo EXIT=!"` 不等待 GUI 子系统程序**：退出码先打印、PNG 后写完，
   于是连续几轮都在读**上一轮**的图，看不出代码改动。改成 bash 直接调用（bash 会等子进程），
   并在每次目检前**先删掉目标 PNG**——同名覆盖写入失败时 mtime 会变而内容是旧的。

## 顺手修的

- 箱内启用开关：原来拿"菜单行高度"当直径，画成 26×34 的白球、圆钮还溢出轨道。
  改成固定 22×12 设计像素、旋钮 `switchH - 2`、居中（像素级复测：胶囊 15 高、钮 12×12）。
- 新增 `-clipauto` 快照（`createClipAutomationSnapshot`）：只开这一帧的箱、给曲线一个形状，
  出图后把 demo 的曲线与视图原位还原——截图布景不写进用户的工程。

## 结果

## Phase 50 — 声相曲线 / 切割 / 反转 / 渲染成采样 / 排版层（2026-10-27 深夜）

用户一句话六件事，一次做完：继续排版层、采样块的第二个自动化目标、曲线与块对齐、

1. **渲染不是第二次混音**。`extract()` 只对**已发布**的 schedule 做过滤，

2. **反转是播放期镜像**，不是重写 buffer。源 buffer 是所有块共享的，
   改它就是"反转一个块，所有同源块一起变"。
3. **插入逻辑抽成自由函数**。原来长在 `MainComponent` 里，自检只能拿活会话试，
