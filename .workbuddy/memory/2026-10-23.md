关键设计决策：
1. **包络按值存在 NoteEvent 里**，不存在 map<noteId, envelope> 外部表。
   复制音符 = 复制整个结构体，包络自动跟随，物理上不可能脱钩。
2. 包络时间是 **归一化的 0..1**（相对于音符长度），不是绝对拍数。
   所以拖动→跟随，拉长→曲线同步拉伸，不需要改任何包络数据。
3. 面板用 (layerIndex, noteId) 寻址，不缓存 NoteEvent*；
   编辑器用 resolver lambda 每次取包络，因为 notes 是 vector，增删会重分配。
4. 递归坑：NoteEnvelope 默认构造调 resetToDefault→makeADSR→再构造，死循环。
   用 `EmptyTag` 私有构造打断。

自检：10 项全 PASS，含"复制音符携带相同包络""改副本不影响原件""删除音符后面板自动关闭"。

关键设计决策：
1. **路由只有一个实现处**。`routing::resolve()` 被音频引擎和所有 UI 读取共同调用，
   面板显示与实际发声不可能不一致。
2. **调度表是不可变快照**。消息线程构建完整 `PublishedSchedule`，
   锁只覆盖 shared_ptr 赋值；音频线程拿到指针后渲染，锁内不做任何音频计算。
   音频线程完全不碰 Layer/NoteEvent/RackModel。
3. 声部**无状态**：相位 = freq × (t - noteStart)，不是逐块累加。
   离线自检和实时播放走的是同一条代码路径。
4. 越级指向已删除音源 → 回落到图层默认，并标记 `danglingOverride`（UI 显示「越级失效」）。

## 踩的坑（重要）
**相位单位错误**：`increment`（cycles/sample）被乘上了秒数，
导致每个音符只走 0.008 个周期 → 正弦变成缓慢爬升的斜坡。
自检的音频断言当场抓到（fadeOut 比值应为 0.18 却得到 1.00）。
正确写法：相位（cycles）= `frequency * elapsedSeconds`，`increment` 只用作 polyBLEP 的步长。

  - 声部 → 每音源立体声总线 → 该音源滤波与推子 → 主输出
  - `LayerMix` / `SlotMix` 快照把推子、声相、M/S、曲线全部冻结

关键决策：
1. **音量自动化 × 推子，声相自动化 + 推子**。乘法/加法各写一次在 `LayerMix::gainAt/panAt`，
   面板读数与音频用同一函数，不会各说各话。
2. **行高是模型的函数**：`getBodyBounds(i)` 累加前面展开的轨道高度，
   所有命中测试都走它，绝不假设 `headerHeight + i*rowHeight`。
3. **宏曲线用绝对拍，音符包络用归一化时间**。两种时间基准是刻意的：

4. 机架自动化编辑器按 **slotId** 重建（不是 index），删音源不会把曲线挂到别的音源上。
5. 包络不自动改变推子：关闭 lane 立刻回到推子值，曲线仍保留。

  不是用 64 拍工程网格。
- 顶栏 保存 / 载入 / 导出 三按钮 + 工程名；Ctrl+S / Ctrl+O / Ctrl+E。

模型新增载入入口：
- `NoteEnvelope::loadPoints` / `AutomationLane::loadPoints`（钳位+排序+最少两点，
  不动 enabled 标志）
- `Layer::restoreNotes`（重算 nextNoteId）、`Layer::setColour`
- `LayerStack::restoreLayers`（一次通知）、`RackModel::restoreSlots`（保留 id）

关键决策：
1. **导出用发布好的调度表快照**。消息线程 publish，后台线程只读 shared_ptr，
   用户在导出时继续编辑不会产生数据竞争。
2. **逐块渲染**。整首当一个块会把自动化只求值首尾两点，滤镜也没有块间记忆。
3. **不做归一化**，只在峰值 >0.999 时拉回（`peakLimited`）。导出必须等于听到的混音。
4. **id 计数器跟着文件走**：`restoreNotes` 把 nextNoteId 设成 max+1，
   `restoreSlots` 把 nextSlotId 设成 max+1，否则新对象会顶掉旧路由。
5. 坏文件必须什么都不改：`fromXmlText` 先建临时 layer/slot 向量，末尾才 commit。

验证：
- 直接导出 demo 与「存盘→载入→导出」得到的 WAV **MD5 完全相同**。
- 导出 63 拍内容 → 31.55 s（含 0.05 s 尾巴），峰值 -18.4 dBFS，RMS 随时间与声像变化。
- 自检覆盖：字段级往返、UTF-8 中文图层名、坏文件被拒且不破坏当前会话、
  WAV 头逐字节校验、数据长度、推子 -12 dB → RMS ×0.251、取消导出不留半截文件。

踩的坑：
- `writeLane` 第三参用 `const char*`，传 `juce::String` 直接 C2664。
- 顶栏原有提示文字与工程名重叠；已删提示，位置留给工程名（信息量更大）。

- 无头模式开真窗口（DocumentWindow）在本机可用，但截图拍不到窗口；
  因此 `--snapshot` 额外输出 `<name>-mixer.png`（直接渲染面板）。

验证：109 项 CHECK 全 PASS（新增：level 居中 / pan 硬右 / pitch 头尾过零 193→149 /
发布期弯曲表 65 点 / 手柄有与无 / 框宽等于音符 / 框不出网格 / 撤销-重做-新建 /
混音台窗口开关 / 设置项）。导出 phase8-demo.wav 31.55 s、峰值 -1.4 dBFS（与 Phase 7 一致）。

## Phase 9（VST3 宿主 / 设置窗 / 音符级挂载）
需求五条：①包络框宽=音符宽 + 窄框换图标 ②齿轮开三页设置 ③自动化窗轨道头缩短
④VST3 乐器进机架、VST3 效果器进通道插槽 ⑤选音符→机架高亮+点别的音源改挂载+图层复位按钮。

落地：
- `Audio/PluginHost`：扫描 / 加载 / 实例表 / `getInstanceWhileLocked` / `resetAllInstancesWhileLocked`
  / `createOfflineClone`（离线导出用独立实例，id 不变）。音频线程 **try-lock**（OptionalLock），
  消息线程阻塞锁；停止/循环用 `pluginPanicRequested` 防挂音。
- 引擎 Stage 1b：宿主乐器直接写 master（不走 layer bus），所以**通道插入管不到 VST3 乐器**，
  主插入/主推子管得到。原生音源走 layer bus → 通道插入。这是刻意的取舍，别写成 bug。
- 插件乐器是**有状态**的：渲染窗口必须从音符起点开始，否则 note-on 落在窗口之外，静音。
  原生振荡器无状态（相位由绝对时间算），两者行为不同，自检里踩过。
- 包络框：`width = jmax(noteWidth, 22)`；`menuArea.getWidth() < 52` 时下拉换图标
  （level=横线+点 / pan=两端竖线+中点 / pitch=上升阶梯 Path）。
- 自动化窗 `listWidth 196 → 140`；参数名要 `withTrimmedLeft(26)`，否则被启用圆点压住。
- 图层「复位N」胶囊 `{202, y+39, 44, 17}`：原本 208/56 宽会压住右对齐的声相读数。
- 工程文件 v4：`PluginDescription::createXml()` 的标签是 **"PLUGIN" 全大写**，
  读的时候必须两种大小写都认（否则 VST 槽静默变空）。`formatVersion = 4`。

踩的坑（都很贵）：
- JUCE 8.0.4 的 `VST3PluginFormat::findAllTypesForFile` **在本进程内 dlopen 插件**读类表
  （moduleinfo.json 只有新包才有）。本机 222 个插件（Arturia/u-he/Steinberg）扫到 Diva/Hive
  直接 SIGSEGV，把 DAW 带走，两次复现。
  → 扫描改为**子进程**：`PluginHost::scan()` 起 `self --plugin-scan-child <out> <paths...>`，
  子进程逐 bundle 写一行 `<PLUGIN/>`（崩溃前找到的都在），父进程等 5 分钟超时 kill 再读文件。
  子进程里再套一层 `__try/__except`（SEH，access violation 不是 C++ 异常）。
- 扫描 149~152 s（222 个），必须缓存：`userAppData/AtomicDAW/plugin-library.txt`，
  首行 `# <search paths 签名>`，路径变了才重扫；`scan(forceRescan)` 给「重新扫描」按钮用。
  第二次 0.00 s。
- `juce_vst3_helper.exe` 仍要拷到 exe 旁（CMake POST_BUILD），否则 JUCE 会提示并回退。
- 插件菜单按厂商分子菜单（90 个乐器平铺就是一堵墙）。
- `XmlDocument::getDocumentElement()` 在 JUCE 8 返回 **unique_ptr**，`auto*` 会编译失败。
- 复用在无头模式：`createSettingsSnapshot` 先 reset 窗口再建，否则设备选择器永远显示 none
  （它靠 timer 刷新，无头模式没人转消息循环）。

验证：120 项 CHECK 全 PASS（新增 13 项：扫描分乐器/效果器、机架接受插件乐器并改路由、
宿主乐器出声 RMS 0.127、主推子 ×0.501、通道 VST 插入 ×0.500、框宽=音符、窄框 22 px、
选中高亮、改挂载写 override、复位清零、设置三页、工程往返保留插件）。
`--pluginscan` 报告本机 222 个插件（90 乐器 / 132 效果器）。导出 phase9-demo.wav 31.55 s / -1.1 dBFS。

## Phase 10（空白启动 / 未保存询问 / 机架自动化进窗）
需求三条：①每次以空白工程启动 ②工程有改动时点关闭弹是否保存 ③音源机架的自动化也创建到自动化窗。

落地：
- `MainComponent::buildSession(bool withEmptyLayer)` 是唯一的重置入口：清 automation / mixer、
  `restoreLayers`、`restoreSlots({})`、BPM 120、清 currentProject、`reconcilePlugins()`（旧插件实例卸掉）。
  空白 = 1 个空图层 + 0 音源；`loadDemoProject()` = `buildSession(false)` + buildDemoContent + applyDemoMixState。
- `RackModel` 构造**仍然**预置 Synth A/B（自检里有 10 处 `RackModel` 直接 `getSlotIdAt(0/1)`，
  改成空会把整套测试拆了）。会话的空机架由 `buildSession` 负责，不要动构造函数。
- 脏标记 = `savedStateText` + `dirtyCache`，**不新增 bool 脏标志**。`commitHistory()` 与
  `applyHistoryPosition()` 负责刷新；save / load / new / demo 置 false 并把 history 重置成单状态。
- 关闭/新建/载入前：`confirmDiscardChanges(action, onProceed)` 三按钮（保存/不保存/取消）。
  `MainWindow::closeButtonPressed()` → `handleCloseRequest()`，返回 false 表示对话框接管、别退。
  `askToSaveProject(onDone)` 带回调，用于「存完再退」。文件选择器与对话框都是异步的，回调链不能省。
- 机架自动化：徽章点击 → `ensureRackAutomationTrack(slotId)`（lane setEnabled + `setAutomationExpanded`
  + `automation.addTrack(slot,…)` + `automationWindow.revealTrack(trackId)`）；右键菜单加轨道后同样展开+滚动到该行。
- 空白工程加第一个音源时，若图层输出悬空就把激活图层指过去（否则新音源静音）。

踩的坑：
- `loadDemoProject` 一开始复用 `buildBlankProject()`，结果 demo 的 3 层叠在空白层的 1 层上 → 4 层，
  最上面是个空的「Layer 1」冒充 demo 第一层。截图一眼看出来（layer0/layer1 都叫 Layer 1）。
- 自检里 `restoreState(before)` 之后不同步 history/historyPos，后续 undo 会回到那块被丢弃的编辑，
  表现是「demo 回不来了」。restore 必须和 history 一起重置。
- 崩溃定位手法：没有 gdb/cdb，加 `ATOMIC_TRACE`（fprintf stderr）逐段缩小范围，
  最后定位到自检 Phase 3 的 `RackModel testRack; // Synth A + Synth B` 假设。用完即删。
- `juce::KeyPress` 的 int 构造是 explicit，`addButton(text, id, KeyPress('s'))` 编译不过。

验证：127 项 CHECK 全 PASS（新增 7 项：空白启动、新建即干净、改动即脏、保存清脏、机架轨道进窗、
徽章展开 lane、新建工程空机架）。新增 `docs/phase10-blank.png`（真实启动画面：空机架提示 + 添加音源按钮）。
