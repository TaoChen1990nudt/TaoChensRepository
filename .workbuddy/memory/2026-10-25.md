# Phase 14 — 自动化改为纯右键菜单

## 需求
去掉所有「自动化」下拉徽章，一律右键控件弹菜单，菜单里有「创建自动化」，
点它才在自动化窗建轨。

## 做法
- `MainComponent::showAutomationMenu()` 重写文案：`创建自动化 · 音量 / 声相`（图层）、
  `创建自动化 · 滤波器 / 音量`（音源），勾选 = `automation.contains(owner, id, target)`。
  第三个实体项是 `展开曲线 / 收起曲线`（徽章删掉后，这是唯一能开关面板内联曲线的入口）。
- 图层行右击 = 这个菜单（原本就是，改文案即可）；机架卡片右击 = `showRackCardMenu`
  里同样两条 `创建自动化 · X` + 一条展开/收起（result 30/31/32，32 是新增的展开开关）。
- 删掉 `LayerPanel::getExpandBounds`、`RackPanel::getExpandBounds`、两边的 `Part::expand`、
  徽章绘制与命中；`RackPanel::onAutomationRequested` / `onAutomationToggled` 一并删除。
- 卡片上原徽章那一行（y+88）改成纯状态行：有曲线 → `● AUTO · 滤波器`，
  没曲线 → `右键：创建自动化`。图层行空出的位置把「复位N」pill 从 x202 挪到 x150。
- 提示文案：自动化窗表头 `右键图层行或音源卡片 → 创建自动化`，
  空态 `还没有自动化轨道 / 右键控件 → 创建自动化`（列表列宽只有 ~180px，别写长句，
  否则 drawFittedText 会折成三行断句）。

## 教训（重要）
`cmake --build | grep -E "error|warning"` 会因为 MSBuild 输出的编码被判成二进制，
grep 只打印一行 "Binary file (standard input) matches" —— 编译其实失败了却看不见，
接着拿没链接的旧 exe 出图，对着一幅旧界面找 bug（徽章明明删了还画着）。
**正确姿势：重定向到日志文件再 `grep -a`，并核对 exe 的 mtime。**

## 结果

`phase14-mixer.png` / `phase14-settings-*.png` / `phase14.log` 已重出。

# Phase 15 — 走带图标 + 时间线 gutter 对齐

## 需求
1. 播放 / 暂停按钮图标乱了，修复。
2. 自动化窗轨道头的右边缘要和钢琴窗钢琴键的右边缘平齐。

## 走带图标（MainComponent.cpp）
- 病根：图标用的是**固定 inset**（`button.getY() + 12 … getBottom() - 12`）。
  Phase 13 把按钮撑到 36 px 高后，播放三角只剩 12x4 的横片；暂停两条横杠的
  上偏移仍是 12，于是整体沉到按钮底部。**图标必须由按钮派生，不能由 inset 派生。**
- 现在：`transportIconBox(button, 0.46f)` 取居中方框，再分 `playGlyph()`
  （宽 = 0.88 方框、整体右移 10% 做视觉配重）、`pauseGlyph()`（两条 0.30/间隔 0.24）、
  `stopGlyph()`（0.86 方框）。三个 glyph 都是文件内自由函数，paint 与自检共用同一份几何。
- 自检 5 条：三角不是薄片 / 三角居中 / 暂停横杠居中（不是贴底）/ 两杠等宽有缝 / 方块居中。

## 时间线 gutter
- 新增 `ui::gutterWidth = px(74)`（Metrics.h），钢琴键 `keyboardWidth` 与自动化窗
  `listWidth` 都指向它。原来是 74 / 140 —— 自动化画布比网格右移 86 px，
  每条曲线都画在错的拍子上，两个视图的播放头也不在一条竖线上。
  实测修好后：小节线完全重合（486 起点，192 px/小节），播放头同在 x=800。
- 列宽从 182 缩到 96 必须重排轨道头：`headerContentTop(row)` 把两行内容垂直居中
  （行高 36..220 都成立），name 10.5sp / 参数 10sp、删除叉挪到**右上角**（11→9）、
  使能圆点挪到参数行左侧并与该行墨迹同中心（`contentTop + px(23)`）。
  实测圆点与文字墨带都是 y 848..857。
- 空态文案要更短：`还没有轨道 / 右键控件创建`；表头标题与轨数收在 96 px 内，
  提示串改从 `listWidth + 10` 起。
- 自检 1 条：`AutomationWindow::listWidth == PianoRollComponent::keyboardWidth`。

## 教训
- **`g.drawText (t, {x, y, w, h}, just, false)` 会 C2668 重载歧义**（花括号初始化列表
  同时匹配 Rectangle 和别的重载），必须写 `juce::Rectangle<int> (x, y, w, h)`。
- 又一次踩到「改完 .cpp 直接出图」：exe 没重链，自检条数没变才发现。
  **改完必须 build 再看 exe mtime 再出图。**

# Phase 16 — 音符编组 · 编组自动化 · 编组挂载 · 音源聚光灯

## 做了什么
- `NoteEvent::groupId` + `NoteGroup` + `groupPalette`（gold/mint/coral/sky/lilac，
  刻意与图层调色板区分）。Layer 增 `addGroup / removeGroup / assignNotesToGroup /
  findGroup / getGroupNoteIds / countNotesInGroup / restoreGroups / getAllNoteIds`。
- 路由升到四层，`routing::resolve()` 加 `viaGroup / danglingGroup`。
- 音频：`PublishedSchedule::groups`（每组一份 `GroupMix`），voice stage 乘组曲线；
  托管 VST3 在 note-on 把曲线值折进 velocity。
- 自动化窗接受 `AutomationOwner::group`，行标题"组 A · 组音量"。
- UI：钢琴窗 `drawGroupBands / drawGroupLabels / drawFocusHighlights`，
  第 6 个工具按钮"编组"，`G` / `Shift+G` 快捷键，组标签可点击选中整组、
  右键组菜单（重命名 / 挂载 / 创建自动化 / 解散）。
- 图层列表与机架卡片都会跟随焦点高亮；机架卡片单击语义改为"聚焦"。

## 关键决策
- 归属存音符，组不存成员表 → 删音符不用清理、复制自动继承、`pruneEmptyGroups()` 兜底。
- 组 id 会话级唯一（`groupIdCounter()`），因为自动化轨道只按 `(owner, ownerId)` 寻址。
- 组曲线是乘法系数不是总线：不进混音器，也不许在混音台长出一条通道。

## 踩坑
- 我把 `for (const auto& group : layer->getGroups())` 里的 `group` 批量替换成 `*group`，
  连 `const NoteGroup*` 那两处也一起改了 → C2100。逐个确认引用 vs 指针。
- 自检标题里混中文会因源文件编码出现乱码，一律写英文标题。
- UI 组测试一度整块跳过：前面的 check 收尾在空工程上，0 音符 → `if (>=3)` 不成立。
  改为在当前图层临时补 4 个音符，断言数 158 → 167。
- 首次出图看不到"组 A"：demo 组原在 beat 48 之后，视野外 → 挪到 8..24；
  同时 `automationPaneHeight` 240 → 270，让 5 条曲线行全部露出。
- **一度误判聚光灯没生效**：我把遮罩后的背景色 `(12,13,17)` 当成原色，
  而它正好是 `kGridBackground(23,24,31) × 0.54`。靠亮度直方图双峰
  （224-255 / 112-127）才确认遮罩是对的。下次先查常量再怀疑代码。
- `复位N` 胶囊 42 单位宽塞 3 个字被迫 8.5pt（低于 9.5 中文下限，糊成一团）。
  输出胶囊 112→102、复位胶囊 150/42 → 140/52，9.5pt 正常。顺手修掉。

# Phase 17 — 采样文件栏、编组栏、四栏滚动与折叠

## 需求
图层栏下方加文件栏（加文件夹 + 拖采样进钢琴窗），采样占整数个音符高度、长度随缩放成比例；
机架栏下方加编组栏（音量/声相/发送音源）；四栏均可滚动；图层/音源/编组都能折叠成一行标题栏。

## 做法
- `Media/SampleLibrary`：手写 RIFF/WAVE 解码（8/16/24/32 int + float32/64 + EXTENSIBLE 0xFFFE），
  不引 `juce_audio_formats`。加载时预算 1024 桶峰值包络，`SampleBuffer` 不可变、shared_ptr 共享。
- `SampleEvent` 进 `Layer` 值成员：`laneSpan`（整数 pitch 行）+ `lengthBeats`，**不存像素**。
  高度 = laneSpan × keyHeight（UI 缩放），宽度 = lengthBeats × beatWidth（横向缩放）。
- `beatWidth` 由常量改成成员（默认 48，12..180，Ctrl+滚轮改），`setBeatWidth` 以视图中心为锚并
  fire `onScrollChanged`，自动化窗标尺才跟着走。
- 采样走图层输出、不经过合成器滤波器；声相用 balance 而非 constant-power（立体声文件不该被压平）。
- 工程文件 v7：`<Samples>` 存路径，读回时重新解码；缺失/解不出则保留矩形、`audio==nullptr`、画淡色。
- 折叠状态一律存模型（`Layer/SynthSlot/NoteGroup::collapsed`），行高 = f(model)，命中全走 getRowBounds。
- 四个列表栏各自持有像素 `scrollY`，`MainComponent::resized()` 只把左右两列各切成上下两块。
- 拖拽：MainComponent 当 DragAndDropContainer，文件栏只 startDragging(path)，
  钢琴窗是 DragAndDropTarget（只认 wav/wave），放下即 `addSampleAt(beat, pitch, file)`。

## 踩坑
- 自检读 `clip->lengthBeats` 时 vector 已被后来的 add 重分配 → 读到野内存，断言假失败。
  凡是"先取指针、之后还会加元素"的地方，先把要用的值拷出来。
- "边落在 lane 边界"按绝对像素取模判断是错的：网格本身有滚动偏移，必须减去 `getGridBounds().getY()`。
- `mixerlook::drawCaret(g,r,false,...)` 原本画朝上三角，收起的行看起来像"已经最大"。
  改成 false = ▶（能再打开），open = ▼。语义参数名 down → open。
- 机架展开态**根本没画折叠三角**（只有收起态画在 X 位置），等于卡片无法折叠。
  挪到 S/M/X 左侧 `right-122`，两种状态同一位置，并收窄名称栏（-90 → -134 / -76 → -130）免撞。
- demo 采样块最初放 beat 28，视野只到 beat 16，出图看不到 → 挪到 beat 12 / pitch 81，
  81..84 是"四行块还塞得进顶边"的最高位置。
- 采样块初版太暗（fill 0.20 / 边框 0.55 / 波形 0.55）在紫色图层上几乎看不见，
  提到 0.32 / 0.85 / 0.90 才读得出波形。

## 结果
179 项自检 ALL PASSED（新增 14 项），零错误零警告。
产物 `docs/phase17.png`(1872x1066) / `phase17-blank.png` / `phase17-mixer.png` /
`phase17-settings-{audio,midi,plugins}.png` / `phase17.log`；顶栏相位 P16 → P17。

# Phase 18 — 指针、吸附、标尺、通道条增删、主输出自动化

## 需求（10 项）
最大化保留标题栏；工具各带指针；吸附按钮（自动化同步）；标尺左键定位播放头；
标尺上下拖拽改横向缩放；新工程内置音源默认发送通道 1；混音台增/删/重置通道条；
效果器机架左右键都弹菜单（在机架下方）；主输出可建音量+声相自动化；
无音源的通道右键不弹对话框、只把菜单项标灰。

## 做法
- 最大化：`setBounds(userArea)` 传的是**内容**尺寸，JUCE 把边框加在外面 → 标题栏顶到屏幕外。
  先减 `peer->getFrameSize()` 四边再 setBounds。
- 光标：`drawPencilImage()` / `drawEraserImage()` 手绘 32x32 ARGB，`MouseCursor(image,hx,hy,1.0f)`；
  铅笔热点 (3,31)、橡皮 (12,26)。`updateCursor()` 由 setTool / mouseMove / 拖拽结束调用。
- 吸附：`numToolButtons 6 → 7`，第 7 个是开关（画 3x3 点阵 + "吸附"）。
  `setSnapEnabled()` 现在 fire `onSnapChanged` → `AutomationWindow::setSnapEnabled()`；
  自动化窗两条 `beatAtX` 调用换成 `snappedBeatAtX()`（网格 0.25，常量写在本文件）。
- 标尺：`DragMode::rulerDrag`。mouseDown 落标尺 = `onLocateRequested(snapBeat(beat))` +
  进入 rulerDrag（光标 UpDownResize）；mouseDrag 用 `beatWidth * pow(1.006, dy)` 缩放；
  mouseUp 调 `updateCursor()` 交还指针。宿主侧 `locatePlayhead()` 用 `audio.setPositionBeats`
  （不是 parkAt：播放中点标尺要 seek 不要停）。
- 默认发送：`buildSession()` 里 `defaultSlot.mixerChannel = 0`（Phase 11 的"不发送"断言已改）。
- 通道条：`MixerModel` 加运行期 `channelCount`（1..8，受 bus 数限制）+ `addChannel/removeChannel/
  setChannelCount/resetChannel` 的模型侧部分；`MixerPanel::getStripCount()` 取代常量 `numStrips`。
  表头 "− / +" 两个按钮；条带右键菜单（MainComponent::showChannelMenu）= 自动化 + 重置 + 删除 + 增加。
  **只能删末尾**：通道号就是索引，删中间会让所有已路由的音源静默改指向。
- 效果器机架：左键也弹菜单（原来左键直开编辑器），锚点用该插槽行左下角
  （`withTargetScreenArea`），菜单在机架下方展开。
- 主输出自动化：`AutomationOwner::master`（ownerId 恒 0）。`MixerModel` 存两条 master lane；
  `PublishedSchedule` 快照 `masterLevel/pan{Automated,Points}`；master 阶段用 `applyGainRamp`
  （音量乘推子、声相加推子，和图层同一条算术）。工程 v8：`<MasterAutomation>` 两个子节点。
- 无音源右键：删掉两个 `showMessage`，改成菜单项 `hasSource` 置灰。

## 踩坑
- `juce::Path::addRoundedRectangle` **没有** 8 个 float 的重载（是 x,y,w,h,csX,csY + 4 个 bool 圆角开关）。
- `AutomationModel::addTrack` 有 `ownerId <= 0 → return -1`，主输出直接被吞，行不出现也不报错。
  改成 `owner != master && ownerId <= 0`。
- demo 加第 6 条轨道后自动化窗最后一行被裁：`automationPaneHeight` 270 → 312，并把 demo 的
  **两条组轨道减到一条**（两条同名行只是把最后一行推到折叠线下）。
- `showChannelMenu` 里 `hasSource && automation.contains(...)` 的短路是刻意的：slotId = -1 时
  别去 contains(-1)。
- 表头文案太长会被截断，删掉"点通道切换右侧效果器机架"那段。

## 结果
186 项自检 ALL PASSED（新增 7 项），零错误零警告。产物 `docs/phase18*.png` + `phase18.log`，
顶栏相位 P17 → P18。

# Phase 19 — 光标中线、音符试听、两端拉伸、标尺分工

## 需求（用户 7 条）
铅笔光标尖端落在笔身中线 / 加音符发声 / 移动音符按新音高发声 / 尾部下拉按钮左移 /
可从左侧调整长度 / 音符太短不显示下拉按钮 / 标尺左键拖播放头、右键拖缩放。

## 做法
- 铅笔光标重画：**在局部坐标里直立绘制（笔尖在原点、沿 −y 延伸、所有形状关于 x=0 对称），
  再 `rotation(π/4).translated(hotX, hotY)`**。之前手摆平行四边形，笔尖偏轴 4 px。
  热点改成 (3,27)，`renderToolCursorImage()` 让 OS 光标和 `--cursor-preview` 共用一套图 + 热点。
  石墨尖用 0xff6b7280 而不是近黑：深色网格上黑尖等于没有尖。
- 试听：`PlaybackEngine::auditionNote(pitch, vel, slotId, retrigger)` +
  `renderAudition()`。**只在 AudioEngine 回调里、masterFade 之后调用**（导出/离线渲染不走它）。
  `retrigger=false` = 拖拽滑音（保留相位、`played` 夹在 hold 内），true = 新音符重触发。
  波形/增益/声相从 `SlotMix`（Phase 19 新增 `waveform` 字段）读，总线走主推子 + 主声相。
  停止时也要渲染：回调的 early-return 加了 `hasAudition()`。
  **`hasAudition()` = engaged || serial != consumed**：只比 engaged 会在"音频线程结尾清标志"
  与"消息线程刚投递"重叠时丢掉一次请求。
- 尾部按钮：`inset = band(6) + gap(3) + width(11)`，`minWidth = inset + band + 6`（设计像素，
  一律 `ui::pf`）。所以右边留 11.7 px 真空给拉伸带；短于 40 px 的实宽直接不画。
- 左端拉伸：`DragMode::resizeNoteLeft`（保持尾端 beat 不变，头端 `jlimit(0, end-grid, x)`）。
  `kResizeHandleWidth` 也改成走 `ui::pf`。
- 标尺：`rulerScrub`（左键，mouseDrag 连续 `onLocateRequested`）与 `rulerZoom`（右键）。
  `updateCursor()` 在 mouseUp 收尾；mouseMove 按 `getCurrentModifiers().isPopupMenu()` 换指针。

## 踩坑
- **JUCE 8 往 `juce::Image` 画图，必须在读/写文件前销毁 `juce::Graphics`**：`--cursor-preview`
  拿着 g 就 `writeImageToStream`，出来一张全透明的图（721 字节），把 g 套进作用域就正常。
- 构建时 exe 被占用（用户开着 app）→ `-p:OutDir=".../build/out19/Release/"` 顶着用。
  注意 `Main.cpp` 的测试插件路径是**从 exe 目录上溯 4 级**找 `AtomicTest*_artefacts/Release/VST3`，
  换到 `C:/atomicout` 会让 5 项 VST3 自检假失败；输出目录必须与正式目录同构。
- `juce::Graphics::drawImage` 没有 (image, Rectangle, placement) 的匹配重载，用 8 参数版。

## 结果

`phase19-cursors.png`（光标 8 倍放大 + 热点十字）、`phase19.log`；顶栏 P18 → P19。
