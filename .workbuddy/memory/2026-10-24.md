   机架卡片菜单（右键或点发送胶囊）：4 种内置波形 + VST3 乐器子菜单 + 发送到通道 +
   自动化 + 删除。
3. **钢琴窗无限往后拖**：`timelineBeats` 从 64 起，`ensureTimelineExtendsTo()` 按
   `beatChunk`(64) 增长，单次最多 +4 块，上限 `maxTimelineBeats`(10000)。
4. **复制音符状态给铅笔**：`paintState` 是整 `NoteEvent` 值拷贝（长度/力度/包络/
   目标参数/越级），音高与位置永远来自点击处。工具条第 5 键 = 复制/再点清除，
   `Shift+Cmd/Ctrl+C` 同效。
5. **通道归音源不归图层**：音频链第 2 级改成 `channelBuses[0..7]`（混音通道）+
   `channelBuses[8]`（直通总线，不经混音器直接进主输出）。

## 关键决定

- `LayerMix` 删掉 `inserts`；新增 `ChannelMix`。`busIndexFor(mixerChannel)` 是唯一映射：
  越界（-1 或 >7）→ 第 9 条总线。未被路由的通道**完全跳过**（不跑插入、不推进延迟线）。
- 宿主 VST3 乐器改成进 `channelBuses[busIndex]`（上一阶段它直接进 master，
  导致通道插入对它无效——这是上一阶段的遗留缺陷，本轮修掉）。
- 工程文件 v5：`Synth` 新增可选 `mixer="0..7"`，缺省 = 不进混音器，旧文件语义不变。
- `PianoRollComponent::resetTimeline()`：会话重建 / 载入工程时把时间线收回默认，
  但**至少覆盖已有音符**（否则载入长曲子后拖不到后面的音符）。`buildSession()` 和
  `loadProjectFromFile()` 各调一次。
- demo fixture 末端把铅笔状态从 Layer 3 第 3 个音符复制出来，截图才有"画笔状态"读数。
- `runSelfTest()` 结尾重新 `loadDemoProject()`：自检会弄脏会话（滚动、发送、加图层），

## 踩到的坑

# Phase 12 — 自动化轨道、窗格伸缩、效果器界面

## 需求（原文要点）

1. 新工程默认自动化窗**没有**轨道；点图层/音源的自动化下拉菜单选参数 → 在自动化窗建轨。
2. 自动化轨道**可上下拖拽换序**，**可改高度**。
3. 钢琴窗时间轴**纵向拖拽伸缩**，钢琴窗与自动化窗**伸缩比例同步**。
4. 混音台各轨道**右键 → 在自动化窗创建自动化轨道**。
5. 混音台右侧效果器机架**点效果器打开界面**。

## 实现

- **`AutomationWindow` 行几何改为累加**：`std::map<int,int> trackHeights`（key = trackId，
  不是 index —— 拖序后高度要跟着轨道走）。新增 `getTrackHeight/ setTrackHeight /
  getContentHeight / rowTopAt / getResizeBounds`；`clampScroll / revealTrack / rowIndexAtY`
  全部改成累加高度，`index * rowHeight` 彻底删除。行底 6px 是 resize 带（`minRowHeight 36 /
  maxRowHeight 220`），hover 时行底线变轨道色。重排阈值改成 `jmax(12, 该行高度*6/10)`。
- **`VerticalSplitter`**（MainComponent.h 里的独立组件）：8px 高、全宽，挡在两个子组件之间。
  为什么必须独立组件：钢琴窗和自动化窗都画到共享边界，落在边界上的点击会被子组件吃掉，
  父组件收不到。`onDrag(deltaY)` 增量回调 → `setAutomationPaneHeight(当前 - deltaY)`。
  `automationPaneHeight` 存**像素**（默认 240），不存比例：用户拖到多少就是多少，
  窗口恢复原尺寸时给回同样的像素。`resized()` 里 clamp 到 `[120, travel-150]`；
  `travel < 200` 时隐藏分隔条和自动化窗（不画两条细缝）。
- **自动化入口统一成 `ensureAutomationTrack(isLayer, ownerId, target)`**：
  lane 开 → 目标参数 → 展开面板 → `addTrack` → `revealTrack` → republish。
  图层徽章 / 图层 lane 的「音量·声相」chip / 音源徽章 / 混音台右键**全部走这一条**。
  图层徽章的点击从"切换展开"改成"弹参数菜单"（菜单里保留展开/收起），
  否则"下拉菜单选参数"这个动作不存在。
- **混音台右键**：`MixerPanel::onChannelAutomationRequested(channel, screenPos)` →
  宿主查 `slotIdOnChannel(channel)` → `showAutomationMenu(false, slotId, pos)`。
  空通道 / 主输出走 `showMessage` 说明原因，不弹一个全是灰项的菜单。
- **效果器界面**：新增 `UI/EffectWindows.{h,cpp}`。
  - `PluginEditorWindow`：`processor.createEditorIfNeeded()` → `setContentOwned`，
    一个实例只能有一个编辑器，第二次"打开"是把已有窗口 `toFront`。
  - `InsertEditorContent` + `InsertEditorWindow`：内置效果器（low pass/drive/delay/air）
    自己画参数窗口，写穿 MixerModel（与条带同一个数）。
  - `PluginHost::getProcessorForEditor(id)`（消息线程、持锁遍历）。
  - `reconcilePlugins()` 里**先同步 erase 窗口再 unload 实例**：窗口按钮的关闭路径是异步的，
    但卸载必须先让 editor 死，否则 editor 析构会碰已释放的 processor。
  - 混音台点击效果名：有内容 → 打开界面；空槽 → 选效果器菜单；右键 → 菜单（含"打开效果器界面"）。
- **时间线同步**：`PianoRollComponent::onTimelineChanged` 在 `ensureTimelineExtendsTo` /
  `resetTimeline` 里触发，宿主把 `getTimelineBeats()` 灌给自动化窗（原来固定用 `totalBeats`，
  滚过 64 拍后两个刻度尺会对不上）。

## 自检

新增 7 项，总数 138 → 145：新工程空窗 / 选参数建轨 / 行高与重排 / 分隔条换高度 /
抓手确实在两窗之间 / 混音台通道建轨 / 空通道无音源。**145 PASS，零 FAIL，零警告。**

# Phase 13 — 启动最大化 + 整套 UI 放大（1.3x）

## 需求
启动时窗口最大化；字体号数加大，各组件加宽加厚。

## 做法
新建 `Source/Util/Metrics.h`：`ui::scale = 1.3f`，`ui::px()` / `ui::pf()`（几何）、
`ui::sp()`（字号）。所有面板常量改成 `ui::px (原设计值)`，所有字体构造包 `ui::sp`，
所有绘制/布局的裸像素数字包 `ui::px` — 代码里写的仍是设计值（"行高 74"），
实际是 96 px。

新建 `Source/Util/UiLookAndFeel.h`：菜单 / 对话框 / 标签页 / 下拉框字体由 JUCE 画，
不走我们的 boldFont，所以单独给一份放大字体，用 `setDefaultLookAndFeel` 安装
（popup menu 属于 desktop，组件级 look&feel 继承不到）。shutdown 里置空。

窗口：`Main.cpp` 里 `setBounds (display->userArea)` 铺满工作区（JUCE 的
DocumentWindow 没有 setMaximised）；`setResizeLimits` 与默认尺寸、`--snapshot`
尺寸（1872x1066）、混音台（1534x390）、设置窗（1066x650）全部按 px() 放大。

## 不缩放的东西（重要）
- `PianoRollComponent::beatWidth`（48 px/拍）与 `numPitches`：这是"看得见多少音乐"，
  不是控件密度。
- 内联自动化框最小宽度 22 px：音符宽度来自 beatWidth，盒子必须"和音符一样宽"。
  自检有两条断言盯这个，第一版误改成 `ui::pf(22)` 立刻 FAIL。

## 结果
153 项自检 ALL PASSED，零错误零警告。
产物 `docs/phase13.png`（1872x1066）等。

- 自检里 `Automation rows resize` 用固定 96/140 px，缩放后仍成立（setTrackHeight 收原始像素）。
