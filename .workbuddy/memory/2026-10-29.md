## Phase 77 — 双击 ghost 换层去编辑

**需求**（用户原话）：在当前图层显示另一个图层作为 ghost note 的情况下，可以双击 ghost note
进入另一个图层进行编辑。

### 一、先划清"不变"的那条线

ghost 点穿是 P1/P20 立的规矩：看不见的图层不能被抓住。这条不动——`getEditableNoteIdAt()`
和所有手势命中仍然只看活动层。新增的只是**双击**上的一条路：双击是"让我过去"，不是"我要抓"，
两个动词。

### 二、接在哪

`handleDoubleClick()` 的顺序原来就是"活动层的东西先问，问完才是空白"：

```
采样块 → 音符 → 组框 → 组名 → （空白：退出组编辑）
```

这个顺序不是随便排的，它就是绘制顺序的倒影：`drawGroupBands → drawSamples → drawNotes →
drawGroupFrames → drawGroupLabels`，而 ghost 是 `drawNotes` 的 pass 1，画在所有活动层内容
下面。所以新分支插在**组名之后、空白之前**——压在 ghost 上面的东西都有优先权。

```cpp
if (const auto ghost = hitTestGhost (pos); ghost.layerIndex >= 0)
{
    stack.setActiveLayerIndex (ghost.layerIndex);      // 换层，会清场
    ...  selectGroup(gid, occ) + enterGroupEdit(gid)   // 组里的
    ...  setSelection({id}) / setSampleSelection({id}) // 不在组里的
}
```

**顺序是语义的一部分**：`setActiveLayerIndex()` 触发 `layersChanged()`，那里无条件关掉
`editingGroupId` 并清空选区（P73：撤销/加载/换层都从这条路进来）。所以选择必须写在换层
**之后**，否则写完就被清掉。

### 三、`hitTestGhost()`

倒序扫层（`drawNotes` pass 1 是升序画的，后画的在上 → 倒序第一个命中的就是看得见的最上面
那个），跳过活动层（它由自己的命中测试回答）和眼睛关掉的层（不可见的东西不可点）。层内先
音符后块——`drawSamples` 在 `drawNotes` 之前，块在音符下面。

### 四、自检 641 → 647（六条）

1. 单击 ghost 仍然点穿（`getEditableNoteIdAt == -1`，活动层不动）；
2. 双击不分组 ghost → 换层 + 选中它；
3. 双击组里的 ghost → 换层 + 进组 + **整次出现**被选中（P74）；
4. ghost 上压着活动层自己的音符 → 双击改的是活动层那个，不跳层；
5. （4b）只有活动层在那有东西时，`getGhostLayerAtForTest()` 答 -1；
6. 眼睛关掉的层，双击它原来的位置不跳过去。

### 五、咬测 5 处

| 植入缺陷 | 结果 |
|---|---|
| `hitTestGhost` 不跳过活动层 | 1 条挂（`1（应为 -1，活动层是 1）`） |
| 不看 `isLayerShown` | 1 条挂（`层 0 / 命中 2`） |
| 跳过去但不进组 | 1 条挂（`0 / 组 -1 / 选中 2 个`） |
| 只选单个成员（`setSelection` 代替 `selectGroup`） | 1 条挂（`0 / 组 484 / 选中 1 个`） |
| 整条 ghost 分支关掉 | 2 条挂 |

第一处**第一次咬空**（零条挂）：活动层的命中排在前面，手势永远走不到那条守卫。按项目老规矩
给了一个能直接问它的钩子 `getGhostLayerAtForTest()`，才咬得住。

### 六、四条夹具教训（都写进 PITFALLS P77-A 了）

1. 测不到的守卫要么删、要么给入口，不能留着当"保险"。
2. 用例撞像素 → 空断言：第 5 条原本拿 `plain` 的位置，可第 4 条刚在同一像素加了 `shadow`。
3. 场景串味：第 3 条接在第 2 条后面，而第 2 条已经把活动层换走了，`grouped` 不再是 ghost。
4. "这一刻像素上有 ghost"要按层问：`shadow` 那个像素上另一层**确实**有音符，答 0 是对的。

### 八、边界

- **只对双击生效**：拖、框选、橡皮、刻刀都还是只看活动层。跨层批量操作没做。
- **ghost 的组框和组名不能双击**：`getGroupFrameAt()` / `getGroupLabelAt()` 只认活动层，
  所以在别的层上双击组框不会跳过去。用户这次说的是音符，块也顺手支持了，组框没动。
- **换层后视口不动**：滚动位置和缩放保持原样。目标音符在换层后可能在视口外（同一次双击
  自己滚过去是另一件事，没做）。
