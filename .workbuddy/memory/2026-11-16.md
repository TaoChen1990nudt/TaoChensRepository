# P112 — 采样块落在行上

用户原话：

> 「在总览状态下显示某一个图层里的采样时，如果有采样在钢琴窗状态下上下重叠，那么总览状态下也应该上下重叠」

## 一句话的根因

P109 写采样块那段注释时，理由是**一句推理**：块没有音高 → 所以画满条带。P112 只做了一件事——
去 `SampleEvent` 里看了一眼：`pitch`（底行）与 `laneSpan`（占几行）从 Phase 17 就在那儿，
钢琴窗里块**就是**占那么多行的矩形。两轮半里「块在总览里撑满」被当成当然，它一直是错的。

## 改了什么

| 位置 | 改动 |
|---|---|
| `UI/PianoRollComponent.cpp` | `+88 −1`。`overviewRowPitches` 加上块占的每一行；新增 `overviewBlockOf`（块＝从 `rank(pitch+span-1)` 的顶铺到 `rank(pitch)` 的底，上下各留 0.5 / 1 px 缝）；新增 `getOverviewSampleBounds`（公开查询，`findSample` 之后转调） |
| `UI/PianoRollComponent.h` | 两个声明 + 三处注释（块的契约、行表口径、`getOverviewRowCount` 的新定义） |
| `UI/PianoRollPaint.cpp` | 块不再 `band.getY()+1 / height-2`，改问 `overviewBlockOf`；行表**提到块之前**建一次，块与音符共用；块的墨 0.13/0.42 → **0.20/0.55** |
| `MainComponent.cpp/.h` | 新增 `createSampleRowsSnapshot`：自带三层夹具（重叠 / 并排 / 单行），不碰活会话 |

## 九条断言

行表含块占的琴键（9 行 / 3 行）、重叠的两块**错开两行且仍交叠**、不挨着的两块不重叠且高的在上、
块落在它那几行上（顶边 = `band + 5 × 行高`、高 = `4 × 行高`）、块比音符线厚三倍、
音符与块共用一张行表（60 的音符落在块的底行里）、`laneSpan == 1` 细成一行且在最下面、
折叠时块仍压满条带（两块 y 区间相同）、越界 / 不存在 / 模式外都答空。

## 四条咬测（每条一次独立编译 + 自检）

## 撞到的两件画面问题

1. **第二条带太淡、也读不出「不挨着」**。原设计是「差一个八度半的两个块」——可略去空键之后
