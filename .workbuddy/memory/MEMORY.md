# AtomicDAW — 项目长期约定

JUCE 8 音频工作站：图层叠加工作区 / 音源机架 / 音符级微观包络。分阶段交付，每阶段只做一件事，
必须能编译并跑通视觉或数据逻辑。

**当前阶段、自检基准、构建命令看 `STATUS.md`；为什么这么做在 `REFERENCE.md`；陷阱在 `PITFALLS.md`。**
本文件只写**不能违反的那一句 + 去哪里找它**；理由不在这里重复。

## 硬规则

1. **中文一律 `atomic::utf8("...")`**，含自检失败信息。裸中文 = 乱码。
2. **几何走 `ui::px()/pf()`，字号 `ui::sp()`**，唯一密度旋钮 `ui::scale`。不缩放三处：
   `numPitches` / gutter / 内联自动化框最小宽度。
3. **路由只有 `Model/Routing.h`**：`resolve()`（音符）、`resolveSample()`（采样，不看组）、
   `layerSlotId()`（兜底跳过 sampler）。UI 高亮与引擎调同一份。
4. **音频线程不读 Layer / NoteEvent / RackModel**。消息线程 `publishSchedule()` 产出不可变
   `PublishedSchedule`；锁只覆盖 shared_ptr 赋值。
5. **改模型后必发 `layersChanged()` / `notesChanged()`**——`pruneOrphanSamplerSlots()` 挂在通知上。
   撤销步合并靠 AsyncUpdater，一趟一次。
6. **唯一入口**：会话重置 `buildSession()`；删槽 `removeSlotAndItsClips()`；撤销 = 整工程快照、
   粒度**一次鼠标手势**（`beginUndoGesture()`/`endUndoGesture()`）；试听分岔 `auditionPreview()`。
7. **组的形状只按「起点 + 名字」配对**（`clipShapeLess`）——配对键不能是形状编辑自己会改的字段。
   改了宽度/窗口/曲线/`laneSpan`，一律 `syncShapeOfClip()` / `syncGroupShape()`。
8. **编组默认是对象，不是容器**（P73）：`enterGroupEdit()` 之前组内按下只回答「整个出现」。
   状态只有 `editingGroupId`，在 `layersChanged()` 里**无条件**清。
9. **按下的话事权归「你以为自己在按的东西」**（P75）：`clipEdgeAt` 答 `(id, none)`；
   组编辑态下组框内的空白不是把手。
10. **选中一个成员 = 选中它所在的编组**（P74）：`armGroupMove` / `expandToWholeOccurrences` /
    `addOccurrenceToSelection`。**扩散只在手势层**，不写进 `setMixedSelection`。
11. **打开不是选择**（P76）：双击进组只改 `editingGroupId`；按在已选中成员上不替换选区
    （`else if (! isSelected)`）。判据是「谁会被缩放」（`dragResizeNoteId`）。
12. **双击 = 打开，顺序照绘制顺序**（P78）：采样那一问排在 `hitTestActiveLayer` **之后**。
    机架卡上**名字是改名、其余是打开**。只有插件槽有窗，内置合成器答 false。
13. **名字是一份数据，不是一个副本**（P79）：三个名字各一处字段，入口都是**双击那行名字**
    （`NameEditor`，位置 = `getNameBounds()`）。例外只有 `SampleEvent::name`。改名按 **id**。
14. **速度一旦会变，时间就是积分**（P80）：唯一换算 `Model/TempoMap`，`secondsPerBeat` 已从全工程消失。
    段内 BPM 线性 ⟹ 求秒取对数、反解取指数；**平坦分支走线性形式**。`renderNextBlock` **每段**重算
    `beatsPerSample`。曲线值到 BPM 是 `60·4^v`。速度图不进 `MixerModel`。
15. **录制的拍号在事件发生的地方取**（P81）：回调里读 `getPositionBeats()`，**beat 随事件一起**过桥。
    音频线程只往预分配 buffer `copyFrom`；`finish()` **先读 `writePos` 再 disarm**。
    写 lane 前必须 `decimateRecordedCurve`（上限 32 点），**少于两点不写**。
16. **一条曲线 = 一个形状 + 一个去处**（P82）：`Model/CurveBank` 三不变量——**目标至多归一条曲线**、
    **列表永不为空**、**用 id 不用下标**。**const 读永不创建**。**「空」在磁盘上是「没有 `target`」**。
17. **两条路径汇到一处，慢的那条不能被拉快**（P83）：`pdc::solve` 是唯一延迟表，补偿只在**汇合点**做，
    绝不延迟源头。**没有插件报延迟 ⟹ 每张表都是 0 ⟹ 渲染逐位等于 P83 之前**——别加「至少 1」兜底。
    延迟线是记忆体：locate / 停止 / `resetMixState` 都必须清。
18. **恢复副本是「一份副本」，不是「那个工程」**（P84）：**写它的路绝不能改 `currentProject`**。
    不变量：**副本存在 ⟺ 有未保存编辑且进程没能正常收尾**。写入走 `File::replaceWithText`，
    **不要 appendOpen**。恢复出来的会话**仍算未保存**。**默认关闭**。
19. **一个类可以住在多个 TU 里，但共享的辅助必须 inline**（P85）：共享层 `UI/PianoRollInternals.h`
    （`namespace atomic::roll`）。**进不进 internals 的标准是「几个 TU 用」**。验收是**逐行比对**。
20. **模型只存绝对路径，相对是文档的形式**（P86）：`Model/SamplePath` 是唯一路径规则层。
    **相对路径必须解得回原文件才写**；**读盘时把修好的位置写回模型**。**重定位不许自动发生**。
21. **循环是一个区间，不是一个标志**（P87）：`Model/LoopRegion`，不变量关于**顺序与最短**（0.25 拍）。
    **开关与数字分开**，关掉不许忘记位置。**`isUsable()` 是唯一判据**。
22. **点击是监听，不是声音，也不是定时器**（P88）：`Audio/Metronome` 混进 `renderNextBlock` 的
    **每个 segment**，`renderInto`（导出/分轨）里没有——「导出拿不到点击」是**结构性的**。
    分句 `ceil(fromBeat - 1e-9)` 让块边界那一拍**只算一次**。**预备拍不改 `positionBeats`**。
23. **量化是形状的改动，不是位置的搬家**（P90）：`quantize::apply` 是唯一规则——`round` 不是 `floor`、
    0 与网格 0 都逐位退回。**只改起点**；`moved == 0` 不重绘也不产生撤销步（判据 `1e-9`）。
    编组先重锚定出现原点，再**无条件** `syncGroupShape`。出现原点是**存下来的数**。
24. **拍号是一个值，不是一个 `constexpr`**（P91）：`Model/Meter.h` 是唯一规则。**`<Transport>` 永远写**；
    **读侧先无条件赋默认再查表**；`setBeatsPerBar` 不调 `modelChanged()`。
25. **拖放的下一个动作由指针底下是什么决定**（P92）：`getGroupReplaceTargetAt` 是唯一判据，预览与松手
    都调它。**自己组的成员不算目标**；**只认同图层**。锚点是**目标的出现原点**。
    **不许用 A 替换 A** 写在函数里。
26. **一个度量只有一个来源**（P93）：`perf::advance` 是唯一负载/峰值规则，平滑 0.2。**丢帧不自己数**
    （`getXRunCount()` 已含设备计数）。**峰值不夹到 1.0**。**预算来自 `numSamples`**。
    顶栏读 `meter::positionAt`，**不许再写字面量 4.0**。
27. **一个 take 有两半，就有两条链、两个偏移**（P94）：监听**默认关**。补偿在 `commitTake` 门口一次做完。
    `getRecordOffsetSamples` = 输出 + **输入** + 监听链；`getMidiRecordOffsetSamples` = 输出 + 监听链
    ——**键盘没走过采集缓冲**。**三个项都不看监听开关**。换算**走秒不走拍分数**。
28. **一遍录音 = 一个容器，只有当前那一遍出声**（P95）：take 集合是**派生的**。**入组只有一个判据**
    `Layer::joinTakeSet`，覆盖率按**长**的那段量（0.9 起）。**`setActiveTake` 是唯一写 active 的地方**。
    发声门在发布（`GroupMix::takeSilent` → `gainAt` 一处）；**它不是 mute**。**`groups` 是 vector**：
    不许跨一次录音缓存 `NoteGroup*`，按 id 取。
29. **拼接是「把这段换成那一遍的材料」，不是一个分段表**（P96）：`Model/Comp.h`（`comping`）是唯一规则。
    **不存 provenance 是设计**。**第一次拼接先分一份**（`NoteGroup::comp`）；第二处接缝改同一份。
    **接缝要的是重叠，不是前后相接**。**淡化在原曲线上乘**且必须插肩点。**切块只走 `splitSampleBlocksRaw`**。
30. **一根柱子只有一个矩形，一次拖动只算一个 delta**（P97）：`Model/VelocityLane.h` 是唯一数值规则
    （**线性轴**、**地板 0.02 不是 0**）。`velocityBarFor` 是唯一几何，paint / 命中 / 框选都问它。
    **lane 里的空白是框选区**：`marqueeInLane` 为真时 `hitsInMarquee` 只收柱子。**快照夹具必须把它改过的
    状态还回去**（`setMixedSelection`）。
31. **说「某功能已有模型」之前先 `grep` 那个符号**（P98）：**「我上次写的」不是证据，源码是**。
    **能复用就不新建**（CC 就是 `AutomationLane`）。**要让规则在无声卡环境里咬得动，就把「何时发送」
    抽成纯函数**（`midicc::valueToSend`）。
32. **一条信号走两条路时，拓扑和延迟是同一个答案**（P99/P100）：`send` 是**并行**的一份，不许指向主输出。
    **控制台从链变成图**：`wouldLoop` 是 BFS（`MixerModel::reaches`），凡 `while (ptr = next(ptr))` 形状的
    判据都要重看。**`pdc::solve` 的边必须带延迟**，排序与延迟表问同一个 `edgeLatency()`。**推子前要第三条线
    `pdcPre`**；`pdcExit` 一块只 push 一次。**return 不是新概念**（`isSendTarget`）。**键是「喂探测器的发送」**：
    存在听者身上（`channelKeys[listener]`），`reaches` 要多扫「谁在听我」。**`noKeySource` 是 -1 不是 0**。
    **模型查环比发布严**。`applyComp` 的 `level` 从 `fx::KeySignal` 还是 buffer 来是唯一分叉；`nullptr`
    与「接了一条静音的线」是两件事。
33. **断言的第一步是让被测对象真的被改变**（P101/P102）：空插入链让两条抽头拿同一份样本。夹具放**会改
    信号**的插入（`drive`，因为**无状态**）。**非线性插入会让「2 倍」失效**——期望 `single + dry`，dry 要
    **量出来**。**断言的前提本身要写成断言**。**参照必须量在「被测对象不存在」的那张图里**，否则同义反复。
    **迟到的插入是属性，不是旋钮**：`fx::builtInLatency(Type)` 是引擎**唯一**的问题，`lookaheadSamples`
    是常量。LIMIT 里**增益乘在延迟之后读出来的样本上**。**空日志 + 秒退（127）= 帧太大**（`/STACK`）。
34. **一个读数要三个动作配套**（P103）：发布**取大**、每块**按速率落**、读完**消费**。少一个意思就变
    （不消费 = 旁通之后表反而**涨**）。换算只有 `fx::gainReductionDb`，回落按 dB/s **减**（电平是乘因子）。
    记的是**这一块乘下去的最小增益**：不是最后那个、不是 `compEnv`、不是含补偿的。表画在**插槽那一行**。
35. **一个读数会不会自己消失，取决于它记的是状态还是事件**（P104）：状态（电平/衰减/负载）自己回落 +
    读完消费；事件（削波）**闩锁**，只在用户点它、或会话被换掉时清零——`resetMixState` **明确不碰它**。
    **满刻度不是削波**（`>` 不是 `>=`）。通道与主输出是**两盏**灯。
36. **几何算「有多大」，绘制算「画哪些像素」**（P105）：`getGroupContentBounds` 是组框唯一来源，**不看视口**；
    「看不见就不画」落在 `drawGroupBands` / `drawGroupFrames` 里各一次 `intersects(area)`。四个读者共用这份
    几何（框、pill、替换预览、命中测试）。pill 两条**互补**规则：左沿夹紧（它是改名与 caret 的把手）、
    整组不可见时返回空。**跟着视口伸缩的框 = 每次滚动抓到不同大小的矩形。** 未修：`getGroupBeatSpan` 不扫块。
37. **不要往别人的窗口里塞宿主的东西**（P107，撤掉 P106）：插件窗口的 content **就是插件编辑器**
    （没界面时是一句说明的 `Label`）。P106 在底部加过一条试听键带，用户看过之后要求去掉，于是
    `AuditionStrip` 与只为「切上下两块」而存在的 `EditorHost` **一起删**——**一个只为一件事存在的
    中间层，那件事没了就该一起没**，空壳是下一个人往里塞东西的邀请。保留的：P42 的按键转发
    （能用但看不见，焦点进插件文本框就静音），这条性质原样不动。要再加「能看见的预览」，找一个
    **不占插件像素**的地方（机架条 / 混音台 / 浮窗），窗口尺寸是插件的事。历史结论仍有效：
    **「窗口长高」与「插件被吃」在内容总高度上是同一个数**，只能比 asked 与 got——同源两个数不能
    互相验证。**撤回也要按改动来验**：断言（`MIN_CHECKS` 降回 1059）、快照帧、四处文档一起撤；
    **一张画着已删控件的图比没有这张图更糟**。跨轮比帧时「本轮两遍相同」**不等于**「与上一轮相同」。

38. **默认值不是一种形状，是「还没有人改过」**（P108）：曲线是改动，「还没改」是一条线。
    `NoteEnvelope::defaultFlatValue = 0.8f` 是**唯一那个数**，三个读者共用（`NoteEnvelope()` /
    `NoteEvent::curves` / 「直线」预设 `makeFlat()`）——**三处各写一个数就一定会漂**，它已经漂过一次
    （默认 0.8、预设 0.7，两个阶段没人发现）。ADSR / 渐弱是**预设**，`resetToDefault()` 回平线。
    **中性点不是全局常量**：音符 0.8（它乘在引擎已塑形的电平上）、采样块 1.0 且停用（它的曲线**就是**
    电平）、声相 0.5。**存盘不动**：文件里写的是音符自己的点，默认值只管「造一个新音符」。
    快照帧：**拷帧按这一轮的清单拷，不按 `glob` 拷**（`/tmp` 里上一次的旧帧会被扫进 `docs/`），
    判据是**帧名集合与上一轮逐字符相等**；`-recovery` 印着时间戳，**跨轮永远不同**，别再推理它。

39. **换一种画法，不是加一层东西**（P109）：同一个工程可以有第二种布局，但它**不移动坐标系**。
    总览把音高这一维收掉（每层一条带，音符是一条起点→终点的细线，只读），**网格的 x 与高度都不动**
    ——`ui::gutterWidth` 是钢琴窗与自动化窗共用的，收窄它 = 曲线跑到错的拍子底下；所以「琴键压成一条线」的
    做法是**不画琴键**，那一列改成名字 + 色条。**带号 == 图层号，不过滤**：P20 的眼睛管的是「叠在身后」，
    总览没有身后，眼睛只改亮度。**只读判据是一行**（`handlePress` 里导航之后、编辑之前），双击/移动/纵向滚轮
    各一行，浮动编辑器进入时关闭。**条带两条边各自取整**，否则中间漏一像素背景。**「按了没反应」证明不了
    只读**——要用同一个像素在两种模式下各按一次，并把它在钢琴窗里的反应写成前提（第五次）。
    视图模式是会话状态（不存盘、`formatVersion` 不动），被它暂时挤掉的开关（力度条）**不许被改写**。
    **一行两段文字量的是笔宽、眼睛看的是墨迹**：提示撞读数时**把句子改短**（P109 时预算 215 px / 十六字，
    P110 加了按钮只剩八字），别用「夹到读数左边」去修——试过 12/4/0/+2 四种间距，只会把 11 张帧的提示打成省略号。

40. **保留一维要先定它的口径**（P110）：总览的带保留音高方向，**行 = 这一层用到的不同音高**
    （`overviewRowPitches`，降序），**行高等分**——「略去间隔的琴键」就是这个等分，所以差 12 个半音与差 1 个
    的行距**一样**。**行表按图层算，不按视口算**（按视口算，横向滚一下线就上下跳）。几何仍只有
    `overviewSegmentOf`：行表传 `nullptr` = 折叠 = `count == 1` = P109 那张图——**折叠不是第二条绘制路径**。
    线厚 = min(条带三成, **行高 55%**) 再夹 1.5–5（少了行高那一夹，C 与 C# 会糊成一块）。
    **屏幕 y 向下长、音高向上长**：`rank 0` 落在 `band.getY()` 那一侧（写反过一次，两条断言当场红）。
    **默认展开**——「重叠要看得见」是画面本身的性质；折叠是给「一层六十个音高」留的出口，模式外点它只 flash。
    代价记着：**行距是层内的相对高低，跨层不可比**（每层一个比例尺）。加一颗按钮花的是提示那一行的预算
    （十六字 → 八字），加之前先想那句话还能短成什么样。

41. **一个开关回答的是「每层各自」的事，就该每层一个**（P111）：总览的折叠从 `bool` 换成
    `std::set<int> foldedOverviewLayers`，**存图层 id，不存带号**——带号是位置，删掉上面一层
    「第 2 层折着」会变成「第 3 层折着」（`Layer::getId` 是工程早就绑定的稳定身份；死 id 的代价
    是一个整数，`clear()` 顺手清）。三个入口同一份状态：左列每层的小三角
    （`getOverviewFoldToggleBounds`，**绘制 / 命中 / 光标三处问同一个函数**，答空 = 这里没有可点的
    东西）、菜单子项、工具栏第 12 颗（亮 ⟺ **全折**，混合态不亮，点击 = 把剩下的折完）。
    **新加的可点区域要证明没把「只读」开漏**：判据只认左列，网格照旧一处不响应；同时钉「点箭头
    不是编辑」（选区/音符数/起点都不动）。视图状态不存盘，`formatVersion` 不动。
    咬测四条：行数忽略折叠红 5 / 折一层变成折全部红 6 / 命中总答第 0 层红 2 / 几何变成整条带红 1。

42. **「它没有 X」和「它有 X」一样，都要先 grep 结构体**（P112）：总览从 P109 起把采样块画满
    整条带，注释理由是「它没有音高」——而 `SampleEvent` 从 Phase 17 就带着 `pitch` 与 `laneSpan`。
    **一层的行 = 音符的音高 ∪ 每个块的 `pitch..pitch+laneSpan-1`**（`overviewRowPitches`）；
    块**盖它的行，不坐在某一行上**：`overviewBlockOf` 从 `rank(pitch+span-1)` 的顶铺到
    `rank(pitch)` 的底——**同几行 = 同一矩形**（重叠），不同行 = 不重叠。折叠时行数 1，块照旧
    压满条带（P109 那张图原样成立，不是第三条路径）。块的墨 0.13/0.42 → **0.20/0.55**：
    面积比「铺满」小多了，不补回来在非当前层上就是一团看不见的糊。
    **断言「重叠」必须同时断言「错开」**——只写「相交」的话，把块改回撑满条带（上一轮的实现）
    它也照样绿，那就不是判据。加一块会**改变同层音符的行**（行数变、等分变），这是「一个音高轴
    管所有东西」的定义，不是失控。咬测四条：块撑满红 4 / 行表不含块红 5 / 忽略 laneSpan 红 3 /
    上下颠倒红 4。加一行块时**别让它落在最低音高**——贴着条带底边会读成一条边框。

43. **一条带占多高，取决于别人折没折**（P113）：用户一句话「折叠之后，整个图层在总览中的宽度也
    变成一条线的宽度」——P109–P112 把每条带钉死成 **1/N**，折叠只回答「几行」，从不回答「占多少
    地方」，于是折起来的层仍然占着整个 1/N，只在中间画一条线、上下全是空气。
    现在带宽是**整摞**的派生量：`getOverviewBandBounds` 先数 `folded` / `open`，折起来的那条 =
    `min (16 设计像素, 等分)`，剩下的高度由 `open` 条带**均分**。两条边界各一个答案：
    **`open == count` ⟹ 逐点等于 P109 的等分**（没折过的画面一像素不动）；**`open == 0` ⟹ 也回
    等分**——没有人可给的时候均摊是不把窗口画成空白的唯一答案，那也正是 P110 说的「像现在一样」。
    **别把 `1/N` 当成不变量**：它只是「没人折」时的特例，凡是从 y 反推带号的地方都要重新想。
    **16 不是新数**，它是 `drawOverviewColumn` 里那句「一个名字需要 16 px」，也是折叠**可逆**的
    最小高度（小三角 = `min (13, 高度 - 4)` ⟹ 16 留得下 12 px 的按钮）。**一个能把东西收起来的
    开关，不许在收起来之后消失**——真要更薄，代价是左列只剩色带、展开只能走菜单，先把这句写在
    代码里再做。**代价**：折一层会让它下面的带全部上移，**缓存的箭头/命中坐标当场失效**（两处按
    下去的测试因此改成每次重新问几何；旧断言「折一层别人的像素逐点不动」被这一轮**反转**，不是
    修 bug）。带宽仍然**每条边各自取整**——两种高度混在一起时，小数落在更短的尺子上。
    咬测四条：不压薄红 5 / 不夹等分红 1 / 全折不回等分红 4 / 腾出的高度丢掉红 3。
